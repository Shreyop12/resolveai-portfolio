# ResolveAI practice resources

These are fictional training materials. Upload them to a new workspace such as `resolveai-practice`; do not use real customer data while learning.

## Setup

1. In **Knowledge**, create/select `ResolveAI Practice`.
2. For the realistic one-handbook test, import `resolveai-practice-support-handbook.md` with category `Support`. Or import the three smaller files when you want isolated retrieval tests.
3. Review each imported draft and click **Publish**.
4. Run the scenarios in `test-cases.md` from the **Support desk** and the **AI lab**.

| File | Suggested category | What it tests |
| --- | --- | --- |
| `resolveai-practice-support-handbook.md` | Support | One source document → several internal searchable sections |
| `01-sso-access-policy.md` | Authentication | Exact-keyword and paraphrase retrieval |
| `02-billing-and-plans.md` | Billing | A second knowledge domain |
| `03-account-security-boundaries.md` | Security | Sensitive-topic escalation boundaries |

Use `evaluation-log-template.md` to record what actually happened. A test does not “pass” because the AI gave a fluent answer; it passes only when the outcome matches the expected safety and grounding behavior.
